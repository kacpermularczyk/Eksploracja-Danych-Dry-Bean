# Eksploracja-Danych-Dry-Bean

Projekt analizujący wpływ metod preprocessing’u na wyniki klasyfikacji zbioru Dry Bean Dataset z wykorzystaniem RapidMiner.

## Dataset
https://archive.ics.uci.edu/dataset/602/dry+bean+dataset

## Preprocessing
Przed uruchomieniem procesu należy usunąć brakujące wartości z zaznaczonych (w skrypcie) atrybutów ciągłych przy użyciu dołączonego skryptu Python.

## Narzędzia
- RapidMiner (AI studio)
- Python

## Uwagi
Normalizacja i dyskretyzacja zostały wykonane przed procedurą Cross Validation w celu zapewnienia spójnych warunków porównania metod preprocessing’u.
